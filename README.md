# Practical-Training2025 个人防护装备检测训练

文档标识：PPE-SUM。版本 0.1，2026-10-03，待评审。源代码基线：`4bb13b0391a2f2581aec488c305a6ddaabde6ac8`。

本项目是基于 Ultralytics YOLO 的个人防护装备（PPE）目标检测训练实训，提供数据目录整理、训练配置生成、YOLOv8n 训练入口和历史训练产物。当前仓库不包含原始 `Dataset/`，不能仅克隆仓库就复现训练结果。

## 当前状态与运行前警告

- 本次整理仅新增文档，不修改训练脚本、配置、权重或历史结果。
- `train_ppe_model.py` 运行时会删除并重建 `datasets_formatted/`，并覆盖根目录 `sh17_config.yaml`。请先备份，避免在含有唯一数据副本的目录运行。
- 脚本生成 **17 类**，已提交 YAML 仅有 **3 类**。必须先核对原始标注的类别编号与目标类别表，不应直接把历史指标当作当前 17 类方案的结果。
- 自动 80/20 划分未固定 Python 随机种子，也未保存划分清单。历史训练参数中的 `seed: 0` 不能证明此前的数据划分可复现。
- 依赖版本未锁定；本次未安装训练依赖、未训练、未加载或验证权重。历史训练记录不等于本次测试通过。

## 安全准备与启动

先阅读 [运行前检查](docs/configuration.md#运行前检查)，在隔离副本中准备经过授权的数据。推荐使用已经划分好的结构，避免每次自动随机重分：

```text
Dataset/
├── images/
│   ├── train/
│   └── val/
└── labels/
    ├── train/
    └── val/
```

标签须与图像同名、使用 `.txt`，类别编号需与脚本类别表一致。脚本不负责转换其他标注格式或校验标签语义。训练和验证目录都应有有效样本。

源码直接依赖 `ultralytics` 和 `PyYAML`；IDE 配置记录 Python 3.10，仅作为历史线索。请先选定兼容的 Python、PyTorch/CUDA 和依赖版本并保存环境记录，详见配置文档。仓库没有经过验证的安装锁定清单。

完成备份、数据核对、环境记录并确认允许覆盖输出后，在仓库根目录启动：

```sh
python train_ppe_model.py
```

默认传入 `epochs=100`、`imgsz=640`、`batch=8`、`workers=0`，实验名为 `ppe_training_result`。实际输出位置以程序打印的 `results.save_dir` 为准。异常被捕获后只打印，不能只用退出码判断成功；必须检查日志、参数、指标和模型文件。
